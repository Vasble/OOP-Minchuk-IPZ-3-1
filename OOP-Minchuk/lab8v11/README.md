Тема: Делегати й лямбда-вирази у практиці колекцій: CollectionHelper<T> Дисципліна: Об'єктно-орієнтоване програмування Варіант: 11

Особливості реалізації:

Логіку підрахунку написано власним циклом foreach + лічильник. Готовий LINQ-оператор Count не використовується.
Якщо collection або predicate дорівнює null, метод кидає ArgumentNullException.
Для порожньої колекції результат — 0.

Відповіді на контрольні запитання
Що таке делегат і для чого він використовується? Делегат — це тип, що зберігає посилання на метод із певною сигнатурою. Він дозволяє передавати поведінку як параметр, зберігати її у змінній і викликати пізніше, наприклад, для зворотних викликів, подій та універсальних алгоритмів над колекціями.
У чому різниця між Func та Action? Func<..., TResult> повертає значення (останній параметр типу — тип результату), а Action<...> нічого не повертає. Predicate<T> — окремий випадок: приймає T і повертає bool.
Як лямбда-вирази спрощують роботу з делегатами? Вони дозволяють описати логіку прямо в місці виклику одним коротким виразом, без створення окремого іменованого методу. Типи параметрів компілятор виводить сам.
Які переваги дають узагальнені методи при роботі з колекціями? Один метод працює з будь-яким типом елементів без дублювання коду, зберігається типобезпека на етапі компіляції, а також не потрібні приведення типів і боксинг.
