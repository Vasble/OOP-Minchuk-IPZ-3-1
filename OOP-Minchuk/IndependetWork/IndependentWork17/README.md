# IndependentWork11 — самостійна робота №17

**Дисципліна:** Об'єктно-орієнтоване програмування
**Тема:** LINQ pipelines: ETL та аналітика
**Платформа:** .NET 10

Опис пайплайнів, використаних операторів, вимірювання продуктивності, аналіз, висновки й відповіді на контрольні запитання — у [REPORT.md](REPORT.md).

## Структура

```
IndependentWork11/
├── IndependentWork11.sln
├── README.md
├── REPORT.md
└── IndependentWork11/
    ├── Models.cs           # Product, Customer, Sale + record-и результатів
    ├── DataGenerator.cs    # генерація тестових даних (Random seed = 2026)
    ├── SalesAnalytics.cs   # 4 LINQ-пайплайни + ручна версія пайплайну 2 для перевірки
    ├── Measurement.cs      # вимірювання часу через Stopwatch
    └── Program.cs          # запуск і вивід результатів
```
