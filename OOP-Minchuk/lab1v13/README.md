Завдання

Створити клас Library з:

приватними полями name, address;
властивістю BooksCount;
конструктором;
методом AddBook().

У програмі створено об'єкти бібліотеки та продемонстровано додавання книг.

Контрольні питання
1. Що таке клас та об'єкт? Яка між ними різниця?

Клас — це шаблон, який описує дані та поведінку об'єктів.
Об'єкт — це конкретний екземпляр класу.

2. Для чого використовуються конструктори? Чи може клас існувати без них?

Конструктор використовується для початкової ініціалізації об'єкта. Клас може існувати без явно створеного конструктора — тоді C# надає конструктор за замовчуванням.

3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?

Приватне поле доступне тільки всередині класу.
Публічна властивість дозволяє безпечно отримувати або змінювати дані класу.
Інкапсуляція потрібна для приховування внутрішніх даних і контролю доступу до них.
