# lab15v11 — Система кешування (варіант 11)

## Структура

| Файл | Призначення |
|---|---|
| `CacheItem.cs` | Елемент кешу (ключ, значення, час оновлення) |
| `AccessRecord.cs` | Запис історії звернень |
| `CacheSystem.cs` | Кеш з обмеженою місткістю на трьох колекціях |
| `Program.cs` | Демонстрація всіх операцій у `Main` |

## Яку підзадачу виконує кожна колекція

- **`HashSet<string>` — унікальні ключі кешу.** Гарантує, що один ключ не потрапить у кеш двічі (`Add` повертає `false` для дубліката, тоді значення лише оновлюється), дає перевірку наявності `Contains` за O(1), `Remove` при видаленні. Додатково: `IntersectWith` (які із запитаних ключів уже є в кеші), `ExceptWith` (яких бракує), `UnionWith` (об'єднання з резервним набором).
- **`Queue<string>` — черга на видалення (LRU).** Новий ключ стає в кінець черги (`Enqueue`). Під час звернення ключ переноситься в кінець, тож на початку завжди лежить ключ, яким найдовше не користувались. Коли кеш переповнений, він видаляється через `Dequeue`; `Peek` показує наступного кандидата.
- **`Stack<AccessRecord>` — історія звернень.** Кожна операція (PUT, GET HIT/MISS, DEL, EVICT) кладеться на вершину (`Push`). `Peek` показує останню операцію, `Pop` дістає записи від найновішого до найстарішого (LIFO).
