## Запуск

Вимірювання продуктивності треба запускати в `Release`:

```bash
dotnet run -c Release --project IndependentWork12
```

Ключ `--quick` запускає лише розмір 1M з одним повтором, для швидкої перевірки.

Повний запуск триває ~15–20 секунд. Результати залежать від кількості ядер процесора, а результати експерименту з побічними ефектами щоразу інші — так і має бути.
