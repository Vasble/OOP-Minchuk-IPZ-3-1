
Лабораторна робота №1
Варіант 13 — Клас Library
Мета роботи

Ознайомитися із середовищем розробки .NET та Visual Studio Code, навчитися створювати класи й об'єкти в C#, використовувати конструктори, властивості та методи, а також налаштувати контроль версій Git і завантажити проєкт на GitHub.

Хід роботи
Встановлено та налаштовано середовище розробки Visual Studio Code.
Додано необхідні розширення C# Dev Kit та .NET Install Tool.
Створено консольний проєкт lab1v13 за допомогою .NET CLI.
Реалізовано клас Library відповідно до 13 варіанту.
У класі Library створено:
приватні поля name та address;
публічну властивість BooksCount;
конструктор для ініціалізації об'єкта;
метод AddBook() для додавання книги.
У методі Main() створено 2–3 об'єкти класу Library.
Викликано методи об'єктів та виведено результати їх роботи в консоль.
Створено файл .gitignore для C#, .NET та Visual Studio Code.
Ініціалізовано Git-репозиторій, створено коміт та завантажено проєкт на GitHub.
Висновок

У ході лабораторної роботи було створено консольний проєкт на C# та реалізовано клас Library із приватними полями, властивістю, конструктором і методом. Отримано практичні навички роботи з класами та об'єктами, а також із Git і GitHub.
